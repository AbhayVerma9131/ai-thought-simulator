# 🧠 AI Thought Simulator

An AI-powered decision engine that simulates structured thinking and helps analyze real-life scenarios using intelligent reasoning.

---

## 🚀 Live Demo
👉 https://your-app-link.streamlit.app

---

## 💡 Idea

Making decisions is often confusing due to multiple factors, risks, and trade-offs.

This project simulates **how intelligent reasoning works**, helping users think through problems in a structured way.

---

## 🧠 What It Does

Given a situation, the AI:

- 🔍 Identifies key decision factors  
- ⚖️ Breaks down pros and cons  
- ⚠️ Highlights potential risks  
- 🎯 Provides a final recommendation  

---

## 🎯 Thinking Modes

The system supports different decision styles:

- 🧠 Logical → Balanced and rational  
- ⚠️ Risk-Averse → Focus on safety  
- 🚀 Growth-Focused → Focus on long-term gains

## ⚙️ How It Works

1. User enters a scenario  
2. Selects thinking style  
3. AI analyzes the situation  
4. Generates structured reasoning output  

---

## 🧪 Example

### Input:
I have two job offers: one high salary, one high learning. What should I choose?
### Output:
- Key factors (salary vs growth)  
- Pros and cons of each option  
- Risks involved  
- Final recommendation
